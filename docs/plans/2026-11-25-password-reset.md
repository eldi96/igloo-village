# 관리자 확인형 비밀번호 초기화

목표: 로그인 화면에서 초기화를 요청하고 eldi 계정만 본인 확인 후 임시 비밀번호를 발급한다.

방식: 임시 비밀번호는 30분·1회 유효한 변경 전용 비밀값이다. Supabase 로그인 비밀번호로 쓰지 않으며, 새 비밀번호를 설정한 다음 정상 로그인한다. 기존 비밀번호를 조회하거나 저장하지 않는다.

구성: api/password-reset.mjs(서버 전용 Auth Admin 호출·운영자 JWT 검증), backend/password-reset.sql(비공개 요청·요청 제한 및 service_role 전용 RPC), password-reset-ui.js(로그인 요청/변경·운영자 처리), backend/client.js 및 auth-ui.js 연결.

작업: [ ] 서버 권한·오류·비밀번호 유출 방지 테스트 → 구현 [ ] SQL 함수/권한 검증 [ ] UI 요청·발급·변경 연결과 브라우저 검수 [ ] 기존 검사 및 문서 갱신.

특히 확인: 없는 계정 응답 동일, 요청 폭주, 임시 비밀번호 만료·5회 실패·재사용, 일반 회원의 관리자 기능 접근, 동시 변경·Auth 변경 실패 시 재시도.

운영 DB 적용·서버 환경변수 설정·배포는 준비 완료 후 별도로 확인한다. 실제 회원 비밀번호는 시험에 사용하지 않는다. 커밋·푸시 없음.
